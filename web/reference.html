06 / How to read this

A scenario, with visible assumptions.

What changes the number

The selected reference supplies observed near and comparison review changes. Edit either trend, the local count, or cost to calculate a new CE. Matched projects subtract per-business changes; Sun Link compares proportional corridor and farther-area growth using its observed baseline reviews per route listing.

What the number cannot establish

The target ZIP is context only. Project type, city, cost, and local density are intertwined in this five-case dataset; it cannot isolate their effects for a new site. Sun Link uses an unmatched method that is not directly comparable with the other references. Reviews are an online activity proxy, not measured visits, revenue, resident welfare, or a causal forecast.

Four references use original matched project rows. Sun Link uses all Yelp listings along its route and an unmatched farther-area growth comparison. Low-support subgroups are withheld. The six other expansion projects are kept out of this calculator. Whole-review sentiment is not sentiment about the project. Topic shares come from a sampled embedding cluster with mixed meaning, so they remain outside CE. Reported costs may combine public and private funding.
